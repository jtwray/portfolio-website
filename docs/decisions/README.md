# Decision Records

Create a short record when a decision materially affects product behavior, architecture, data handling, accessibility policy, deployment, or future work.

Use `YYYY-MM-DD-short-title.md`:

```md
# Decision title

Status: proposed | accepted | superseded

## Context

What prompted the decision?

## Decision

What did the owner approve?

## Consequences

What becomes easier, harder, required, or excluded?
```
